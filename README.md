# 🎭 Fancy Dress Rental Website

A responsive web application that allows users to rent fancy dress costumes for school events, cultural programs, Halloween, cosplay, themed parties, and special occasions. The platform provides an easy-to-use interface for browsing costumes, placing rental orders, and managing bookings.

---

## 📌 Features

- 👤 User Registration & Login
- 🎭 Browse Costumes by Category
- 🔍 Search Costumes
- 🛒 Add to Cart
- 💳 Online Payment Integration
- 📅 Costume Rental Booking
- 📦 Order Management
- 🔄 Return Management
- 📱 Responsive Design
- 📧 Contact Form

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/FancyDressRental.git
```

2. Copy the project into the **htdocs** folder.

3. Start Apache and MySQL using XAMPP.

4. Import the database into phpMyAdmin.

5. Open your browser.

```
http://localhost/FancyDressRental
```
